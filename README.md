# front-map

Интерактивная карта: рисование, слои, стили объектов и история изменений по дням.

**Приложение:** https://molostov-a.github.io/front-map/

Для входа нужна учётная запись, созданная администратором. Клиент использует
MapLibre GL JS и JavaScript ES-модули, API работает отдельно на Node.js и SQLite.

## Возможности

- Линия, полигон, точка с подписью, текстовая надпись, стрелка и линейка.
- Стили заливки, обводки и текста; редактирование вершин и перенос фигуры.
- Слои, календарь истории, версии объектов на каждый день.
- Длина линий, площадь полигонов и шкала измерительной линейки.
- Роли viewer/editor/admin и плавающие панели интерфейса.

## Разработка

Node.js 20, npm:

```bash
npm ci
npm run lint
npm run typecheck
npm test
npm run build
```

Результат сборки — `dist/`. В разработке исходники можно раздавать HTTP-сервером;
API должен быть запущен отдельно. На localhost `config.js` использует тот же origin.
При отдельном frontend-сервере задайте `window.__FM_API_BASE` до загрузки конфигурации.
Production API настраивается в `config.js`. Ключи и пароли сюда не добавляются.

Полный локальный проект содержит соседнюю папку `backend/` (приватный репозиторий)
и корневые утилиты. В таком checkout `node tools/check.mjs` из корня выполняет
все проверки и браузерный E2E на временной БД; `node tools/browser-preview.mjs`
под Node 20 открывает собранный клиент в подпапке `/front-map/` для ручной проверки.

## Публикация

Push в `main` запускает lint, типы, тесты, сборку и деплой `dist/` через GitHub
Actions на Pages. Внешние vendor-импорты должны быть относительны к итоговому
бандлу (`./vendor/`), чтобы работать при размещении в подпапке.

## Управление

Линия, стрелка и линейка завершаются вторым кликом; Shift включает многоузловое
рисование. Полигон замыкается кликом по первой точке или Enter. Esc отменяет
черновик, Delete открывает удаление. Изменения стиля отправляются автоматически
с задержкой 300 мс. Календарь и кнопки ‹/› переключают день; «Сейчас» возвращает
сегодня. Полное удаление объекта или слоя удаляет историю.

Архитектура, правила изменений и контракты тестов — в [AGENTS.md](AGENTS.md).

## Операции и история полигонов

Выберите полигон A и второй полигон B в его свойствах. Объединение и вырезание
работают с предварительным просмотром: A синий, B оранжевый, результат фиолетовый.
Можно создать новый объект или сохранить результат как A/B; судьба остальных
исходников выбирается отдельно. Поддерживаются отверстия и MultiPolygon.

«Сравнить даты» показывает добавленные и удалённые части каждого полигона.
У каждой категории собственные настраиваемые цвета заливки и контура, есть
легенда площадей. Настройки хранятся в браузере; сравнение доступно viewer и
не меняет данные. Смена дня или редактирование сбрасывает устаревшую подсветку.

Геометрическое ядро — polygon-clipping 0.15.7; browser-vendor и лицензии лежат
в `vendor/`. Для воспроизводимой пересборки: `npm run vendor:polygons`.

Палитра сравнения находится в свойствах полигона, включая отдельные цвета
неизменившихся участков. Кнопка в панели дат открывает эти настройки без включения
рисования. Добавленные/удалённые части остаются отдельными категориями.

Инструмент «Пипетка»: источник → получатель; Shift+клик берёт другой образец,
Esc выходит. Переносится оформление всех типов и совместимые поля между типами.
Текст, координаты, касательные, сглаживание и размеры/форма стрелок сохраняются.


Сравнение дат открывается сверху справа; его палитра — первая секция свойств
полигона. Shift/Ctrl+клик выделяет несколько полигонов: операции открываются
отдельным окном с переключением всех пересекающихся пар стрелками.
Применение выполняется для текущей пары после предпросмотра.

В списке слоёв: общая непрозрачность 0–100%, порядок ↑/↓, копирование ⧉
в другой слой (весь снимок выбранного дня или выбранные объекты).
Копии получают новые id; геометрия и оформление оригиналов сохраняются.
Окна копирования и операций можно перемещать за заголовок.
