# front-map

Интерактивная карта: рисование, слои, стили объектов и история изменений по дням.

**Приложение:** https://molostov-a.github.io/front-map/

Для входа нужна учётная запись, созданная администратором. Клиент использует
MapLibre GL JS и JavaScript ES-модули, API работает отдельно на Node.js и SQLite.

## Возможности

- Линия, полигон, точка с подписью, текстовая надпись, стрелка и линейка.
- Стили заливки, обводки и текста; редактирование вершин и перенос фигуры.
- Слои, календарь истории, версии объектов на каждый день.
- Длина линий, площадь полигонов и шкала измерительной линейки.
- Роли viewer/editor/admin и плавающие панели интерфейса.

## Разработка

Node.js 20, npm:

```bash
npm ci
npm run lint
npm run typecheck
npm test
npm run build
```

Результат сборки — `dist/`. В разработке исходники можно раздавать HTTP-сервером;
API должен быть запущен отдельно. На localhost `config.js` использует тот же origin.
При отдельном frontend-сервере задайте `window.__FM_API_BASE` до загрузки конфигурации.
Production API настраивается в `config.js`. Ключи и пароли сюда не добавляются.

Полный локальный проект содержит соседнюю папку `backend/` (приватный репозиторий)
и корневые утилиты. В таком checkout `node tools/check.mjs` из корня выполняет
все проверки и браузерный E2E на временной БД; `node tools/browser-preview.mjs`
под Node 20 открывает собранный клиент в подпапке `/front-map/` для ручной проверки.

## Публикация

Push в `main` запускает lint, типы, тесты, сборку и деплой `dist/` через GitHub
Actions на Pages. Внешние vendor-импорты должны быть относительны к итоговому
бандлу (`./vendor/`), чтобы работать при размещении в подпапке.

## Управление

Линия, стрелка и линейка завершаются вторым кликом; Shift включает многоузловое
рисование. Полигон замыкается кликом по первой точке или Enter. Esc отменяет
черновик, Delete открывает удаление. Изменения стиля отправляются автоматически
с задержкой 300 мс. Календарь и кнопки ‹/› переключают день; «Сейчас» возвращает
сегодня. Полное удаление объекта или слоя удаляет историю.

Архитектура, правила изменений и контракты тестов — в [AGENTS.md](AGENTS.md).
